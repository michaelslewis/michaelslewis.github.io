About Me

Data Engineer specializing in SQL, Python, dbt, Snowflake, and modern analytics engineering platforms. I build reliable data pipelines, analytics-ready data models, and scalable transformation workflows that turn complex enterprise data into trusted business insights.

My background in software quality engineering shapes my approach to data engineering. Featured Project

Structifact

Structifact is an analytics engineering framework exploring metadata-driven data workflows, schema validation, transformation workflows, and analytics-ready modeling using Python, SQL, DuckDB, and Parquet.

Structifact is a metadata-driven analytics engineering framework that converts declarative schemas into repeatable data transformation workflows, enabling validated, analytics-ready datasets from heterogeneous source systems.

Structifact explores modern analytics engineering principles including schema- driven ingestion, metadata-based orchestration, automated validation, reusable transformations, and analytics-ready modeling.
